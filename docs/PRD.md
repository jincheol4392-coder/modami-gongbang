# 사이트 설계도(PRD) — 커플 향수 원데이 클래스 (공방 이름 미정)

작성일: 2026-11-03 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
영천시 완산동에서 커플이 함께 나만의 향수를 만드는 원데이 클래스 공방.

## 2. 손님
- 누가: 주말 데이트를 찾는 커플
- 어디서 알고 오나: 인스타그램 (프로필 링크 → 사이트)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격 (2인 기준)
2. (미정)
3. (미정)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 수업·공방 사진
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 카카오톡으로 문의하기
- 누르면: 카카오톡 채팅으로 연결 (링크 미정 — 정해지면 넣는다)

## 6. 페이지 구성 (위에서 아래로) — 한 페이지
1. 첫 화면 — 한 문장 + 카카오톡 문의 버튼
2. 클래스 안내 — 무엇을 만드나(향수), 가격(2인 기준), 시간(금요일 2시, 2시간), 위치(영천시 완산동)
3. 수업·공방 사진
4. 후기 자리 (비워 둠)
5. 마지막 카카오톡 문의 버튼

## 7. 문의 폼에서 받을 것
- 이번엔 문의 폼 없음 — 카카오톡 버튼으로만 문의를 받는다
- (폼을 만들게 되면: 이름, 연락처, 원하는 날짜, 개인정보 수집·이용 동의(필수))

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 클래스: 향수
- 가격: 2인 기준 (금액 미정)
- 시간: 금요일, 2시, 2시간
- 위치: 영천시 완산동
- 연락 방법: 카카오톡 (링크 미정)

## 9. 이번에 넣지 않을 것
- 문의 폼·문의 저장(Supabase)·관리자 페이지(/admin)
- 회원가입·로그인
- 온라인 결제
- 사진 올리기, 알림 메일

## 10. 첫 화면 한 문장 후보
1. 둘이 함께 만드는, 세상에 하나뿐인 우리의 향
2. 이번 데이트는 서로를 닮은 향수 한 병으로
3. 영천 완산동, 커플을 위한 향수 원데이 클래스

## 11. 다음에 할 것
- 공방 이름, 2인 가격, 카카오톡 링크 정하기
- 손님이 궁금해할 것 2·3번 정하기 (예: 초보 가능 여부, 완성품 가져가기)
- 실제 후기가 생기면 후기 자리 채우기
- 필요하면 문의 폼 + 관리자 페이지 추가 (leaderpl-admin 스킬)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 아니오 → 카카오톡 버튼만
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. (문의 저장은 '아니오'라 이 단계는 건너뛴다)
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제
